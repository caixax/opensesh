# ADR 0026: MSRV 1.89, for russh's fixes

- **Status:** accepted (raises the MSRV of [ADR 0002](0002-toolchain-and-msrv.md))
- **Date:** 2026-09-27
- **Sprint:** 7

## Context

Sprint 7 builds the SSH client on `russh` (PLAN §2). Its current releases, checked on crates.io and in the project's release notes on 2026-09-27:

| Version | `rust-version` | For a client |
|---|---|---|
| 0.63.1 | 1.85 | fixes GHSA-47hw-gvq5-r2gm (client callbacks with invalid channel ids) and GHSA-p8qx-h547-fjw9 (a cipher negotiated without its MAC panics) |
| 0.63.2 | 1.89 | terminal modes in `pty-req` sent correctly, sensitive data redacted from debug logs, a write split across a rekey no longer breaks, the hash algorithm of RSA certificates, and GHSA-g4mp-vgx3-xrvm (an out-of-bounds read with a malicious Pageant) |
| 0.63.3 | 1.89 | the inactivity timeout also works during stalled writes |

With our MSRV at 1.88, resolver 3 stops at 0.63.1. That release lacks fixes a terminal client needs; the log redaction also matters for our rule that secrets never reach logs.

## Options

1. **Stay on 1.88 with `russh` 0.63.1,** and wait for backports. There are none for the 0.63 line, and we would ship known bugs.
2. **Raise the MSRV to 1.89** and use 0.63.3.
3. **Toolchain on latest stable, MSRV on 1.88:** that is ADR 0002's rejected option 1, and it still can't use 0.63.3, whose `rust-version` is 1.89.

## Decision

Option 2.

- `rust-toolchain.toml` pins `1.89.0` and `workspace.package.rust-version` is `1.89`. Every local and CI build still proves the MSRV (ADR 0002).
- `russh` is pinned at `0.63.3`.

## Consequences

- Rust 1.89's clippy extends `collapsible_if` to `if let` chains. Twenty-one files changed mechanically (`if a { if let b ... }` becomes `if a && let b ...`), with no change in behavior. The 481 tests, clippy and the smoke tests pass on 1.89.
- Distro compilers are older still. Contributors keep using rustup, which installs 1.89.0 on the first `cargo` run.
- The next bump follows the same rule: the toolchain file, `rust-version` and an ADR together.
